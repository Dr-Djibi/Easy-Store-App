# 📱 Menma Store App (Admin Mobile)

Application mobile développée en React Native (Expo) servant de télécommande / panneau d'administration pour la boutique Menma Store.

## 🚀 Caractéristiques
- **Configuration dynamique de Supabase** : Saisissez vos clés Supabase pour connecter l'application à n'importe quelle instance.
- **Gestionnaire de Produits Modulaires** :
  - Création / Modification / Suppression de produits.
  - Ajout de blocs personnalisés [Grand Titre] + [Texte d'accroche] + [Image d'illustration].
  - Réorganisation à la volée (Monter, Descendre, Supprimer).
- **Gestion des Commandes** :
  - Suivi des commandes reçues avec statuts (Nouveau, Confirmé, Livré, Annulé).
- **Réglages Boutique & WhatsApp** :
  - Choix de la devise locale (GNF, XOF, MAD, etc.).
  - Personnalisation des champs du formulaire de commande et des numéros WhatsApp.

## 📦 Commandes
```bash
npm install
npx expo start
```
